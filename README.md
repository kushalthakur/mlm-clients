## mlm react-d3-tree
Multi Level Marketing front-end React.Js.<br />
TypeScript, React.Js, Redux, Redux-Saga, Meterial-ui and Function Component.<br />

## Project setup

In the project directory, you can run:
1. ``` npm install ```
2. ```npm start```

Runs the app in the development mode.<br />
Open [http://localhost:PORT](http://localhost:PORT) to view it in the web browser.

## Features available in the application:
1. Perfect Folder Structure
2. Login
3. Admin create mlm tree

## Compiles and minifies for production
```npm build```
